LOKI MONITORING SETUP NOTES
============================

1. How Loki was started (local Docker run):
---------------------------------------------
docker run -d --name=loki -p 3100:3100 grafana/loki:2.9.0 -config.file=/etc/loki/local-config.yaml

(Optional) Start Grafana to visualize logs from Loki:
docker run -d --name=grafana -p 3000:3000 grafana/grafana:latest

Then open http://localhost:3000, add Loki as a data source using URL http://localhost:3100.

2. Forwarding container logs to Loki:
---------------------------------------------
docker run --log-driver=loki \
  --log-opt loki-url="http://localhost:3100/loki/api/v1/push" \
  --log-opt loki-external-labels="job=hello-devops" \
  devops-intern-final:latest

(Requires the Loki Docker driver plugin:
docker plugin install grafana/loki-docker-driver:latest --alias loki --grant-all-permissions)

3. Command used to view logs:
---------------------------------------------
curl -G -s "http://localhost:3100/loki/api/v1/query_range" \
  --data-urlencode 'query={job="hello-devops"}' | jq

Or in Grafana: Explore tab -> Loki data source -> query: {job="hello-devops"}
